## 一、「更多」→「设置」无反应

- **现象**：点左下角「更多」→「设置」后没有任何弹出层，设置模态没有打开。
- **根因**：v2.8.3-beta.4 起，官方账户菜单触发行被隐藏，「设置」并入产品「更多」浮层。
  旧实现通过“点击隐藏的官方触发按钮 → 再点菜单里的设置项”来打开设置；这条 DOM 桥接
  依赖菜单渲染、焦点和隐藏元素的可点击性，在部分真实环境/配置下不稳定，菜单项没有触发，
  用户看到的就是“点了没反应”。
- **修复**：优先从官方账户 launcher 的 React props 里直接取 `openSettings` 并调用 ——
  这是上游自己传给 launcher 的动作，打开的仍是官方设置模态，行为和快捷键/账户菜单完全一致。
  只有取不到 React 内部属性时才回退到原来的 DOM 菜单桥接。
- **验证**：E2E 断言「更多」→「设置」能打开设置模态、账号页可达、关闭后焦点正常。

- 本版只修客户端交互；beta.3 的能力与限制不变。
