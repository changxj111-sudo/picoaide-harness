## 一、技能管理白屏

- **现象**：会话页点顶部「技能」Tab，再点子 Tab「技能管理」，页面变成白屏。
- **根因**：DSH 0.2.1 的 `@deepseek-ai/dsh-client-ui-primitives` 移除了带像素后缀的图标导出
  （`IconSearchOutline16`、`IconFolderOpen16`、`IconChevronDownOutline14` 等），改名为
  `…Regular` / `…Medium`。memory-evolve 的技能管理组件仍按旧名字导入；平台模块是
  external，构建期不校验这些名字，运行时拿到 `undefined` 后 React 渲染直接抛错，
  整个会话页面被卸载成白屏。
- **修复**：技能管理（SkillsBrowser）与无限画板（CanvasView）里所有旧图标名改为新导出：
  `…16` → `…Regular`，`…14` → `…Regular`。同时更新已提交的 `lib/client.js`。
- **验证**：新增 `tests/icon-exports.test.js`，扫描源码与产物，禁止再出现旧像素后缀图标名；
  E2E/构建后页面应能正常渲染技能列表、目录树与编辑器。

## 二、继承 beta.4 / beta.5 的界面修复

- 左下角只保留一个「更多」；「设置」并入「更多」浮层；浮层实底。
- 上游菜单（视图选项等）在原生材质窗口下启用 `[data-menu-backing]` 实底。

## 已知限制

- 本版只修客户端渲染；beta.3 的能力与限制不变。
- 旧的自定义技能目录/状态不受影响。

## 升级与回滚

- 服务端：取本版镜像附件，按 `docs/deploy/AI-DEPLOY.md` 升级；升级前必须备份。
- 客户端：随服务端镜像分发，员工从自己登录的服务器取包。
- **回滚**：本版无数据库迁移，保留上一版镜像 tag 切回即可；客户端重装 beta.5 包。

- **迁移清单（机器可读锚点，供 `scripts/check-release-notes-migrations.mjs` 与 `git diff` 对拍）**：无
